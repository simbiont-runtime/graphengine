# Security Policy

## Security Philosophy

GraphEngine is infrastructure software.

Security, reliability, and correctness are treated as first-class concerns throughout development.

## Reporting Vulnerabilities

Please report security issues privately before public disclosure.

Include:

- Vulnerability description
- Reproduction steps
- Impact assessment
- Suggested mitigations if available

## Security Priorities

Current priorities include:

- Input validation
- Query execution safety
- Dependency management
- Distributed execution security
- Secure development practices

## Future Work

Planned initiatives include:

- Repository threat modeling
- Automated vulnerability analysis
- Security testing pipelines
- Continuous security review
